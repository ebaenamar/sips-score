SIPS Score

Paste a public GitHub repo. We read the code and git history (nothing is run) and tell you where your AI loop puts the person, how much that time is worth, and what would raise the score.

We store the repo URL, team name and the result to improve SIPS. Private repo? Run it locally: pipx install git+https://github.com/ebaenamar/sips-score

API 
curl -X POST https:///api/score \
  -H 'content-type: application/json' \
  -d '{"repo":"https://github.com/owner/repo","team":"my-team"}'
